对外发布的数据集号称已匿名，可用邮编加年龄一交叉，每个人都能被单独定位出来：发布前的每一份数据都必须按准标识符划分等价类，每个等价类至少包含 k 条记录；泛化必须覆盖全部准标识符；泛化不能只做一次，要迭代到每个等价类都满足 k 为止；输出不得保留唯一可识别字段；同一输入两次泛化的结果必须相同；批量处理时各数据集彼此独立。输出中的不变量：不存在少于 k 条的等价类，且同一输入两次泛化结果一致。

数据以记录列表表示，记录是列名到取值的映射；配置包含准标识符列、k 值、唯一标识列以及允许发布出去的列。泛化结果为每份数据给出输出记录与是否满足 k 的标记，输出只保留泛化后的准标识符列，输出行数与输入中不重复的记录数一致，重复出现的同一条记录只计一次。

自检方式：在仓库根执行 python -m pytest tests -q ，测试全绿即表示上述契约与不变量均成立。
